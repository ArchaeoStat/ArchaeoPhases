# Phases

A data set containing information on the start and end dates of two
phases.

## Usage

``` r
mcmc_phases
```

## Format

A
[`data.frame`](https://ArchaeoStat.github.io/ArchaeoPhases/dev/reference/data.frame.md)
with 30,000 rows and 5 variables:

- `iter`:

  Iteration of the MCMC algorithm.

- `P2_alpha`:

  Start date of Phase 2.

- `P2_beta`:

  End date of Phase 2.

- `P1_alpha`:

  Start date of Phase 1.

- `P1_beta`:

  End date of Phase 1.
